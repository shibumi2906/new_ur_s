# AI Document Creator Agent

Интеллектуальный агент для автоматизации создания и заполнения документов на сайте https://app.conneto.com с использованием GPT-4o и Selenium.

## 🎯 Основные возможности

- **Интеллектуальная навигация** - агент анализирует DOM, планирует действия через LLM, выполняет и корректирует ошибки
- **Взаимодействие с пользователем** - LawyerAgent ведет интерактивный диалог и собирает данные для заполнения документов
- **Самокоррекция** - автоматическое исправление ошибок Selenium с помощью GPT
- **GUI интерфейс** - удобный графический интерфейс, включая полноэкранный лог и панель «Диалог с юристом»
- **Модульная архитектура** - построен на LangChain с разделением на агентов и инструменты

## 🏗️ Архитектура

### Агенты (agents/)
- **MainAgent** - основной координатор всего процесса
- **NavigatorAgent** - определяет текущее состояние страницы и возвращает объект с `state`, `analysis`, флагами
- **PromptGeneratorAgent** - генерирует промпты для LLM (в т.ч. для страницы Options: «Create from template»)
- **LawyerAgent** - ведет диалог с пользователем, задает вопросы на основе HTML формы и генерирует юридические формулировки

### Инструменты (tools/)
- **SeleniumTool** - выполняет Selenium код (в контекст исполнения передаются `credentials` и `user_data`)
- **PageContextTool** - собирает контекст страницы (элементы, HTML, URL)
- **ErrorFixTool** - исправляет ошибки в коде

### Память (memory/)
- **AgentMemory** - хранит историю действий, ответы пользователя и ошибки

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
# Активация виртуального окружения
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac

# Установка пакетов
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Создайте файл `.env` на основе `env_example.txt`:
```bash
cp env_example.txt .env
```

Заполните в `.env`:
```
OPENAI_API_KEY=your_openai_api_key_here
DEFAULT_EMAIL=your_email@example.com
DEFAULT_PASSWORD=your_password
```

### 3. Запуск
```bash
python gui_agent.py
```

## 📋 Рабочий процесс

### Пошаговая последовательность создания документа

1. **LOGIN** — страница авторизации (вход в систему с данными из GUI)
2. **PAGE_1** — главная страница после входа
   - Найти кнопку «Documents» в левом меню и нажать
3. **PAGE_2** — список документов (URL: `app.conneto.com/contracts`)
   - Найти кнопку «New document» и нажать
4. **CREATE_FROM_TEMPLATE (Options)** — выбор способа создания (`/create-contract/options`)
   - Найти и нажать кнопку «Create from template»
5. **PRELIMINARY_DATA (Details)** — форма предварительных данных (`/create-contract/details`)
   - ✅ Активируется LawyerAgent — собирает обязательные поля (название файла, язык документа) и опциональные (номер, проект)
   - После сбора данных форма заполняется и нажимается «Continue»
6. **TEMPLATE_SELECTION** — выбор шаблона (`/create-contract/templates`)
   - LawyerAgent уточняет у пользователя цель и предлагает подходящий шаблон
   - Нажимаем на выбранный шаблон
7. **DOCUMENT_FILLING** — заполнение полей выбранного шаблона
   - LawyerAgent задает вопросы по реальным полям формы и передает `user_data` в Selenium-код для заполнения
8. **COMPLETION** — завершение, сохранение и показ результата

### Ключевые моменты активации LawyerAgent
- На **PRELIMINARY_DATA** — сбор обязательных полей перед заполнением формы
- На **TEMPLATE_SELECTION** — помощь в выборе шаблона и согласование с пользователем
- На **DOCUMENT_FILLING** — сбор содержательных ответов для полей шаблона

## 🎛️ GUI интерфейс

- **Учетные данные** — поля для email и пароля (предзаполнены)
- **Лог работы** — отображаются все сообщения (фильтра нет)
- **Диалог с юристом** — интерактивная панель: вопросы/ответы идут напрямую
- **Статус** — текущее состояние агента
- **Управление** — кнопки запуска/остановки агента

## 🔧 Конфигурация

Основные настройки в `config.py`:
- `LLM_MODEL` — модель GPT (по умолчанию `gpt-4o`)
- `BASE_URL` — базовый URL сайта
- `MAX_RETRIES` — максимальное число попыток при ошибках
- `SELENIUM_TIMEOUT` — таймаут ожиданий Selenium

## 📝 Логирование

- Все сообщения отображаются в окне GUI (и дублируются в консоль).
- История ошибок Selenium доступна из `SeleniumTool.get_error_history()`.

## 🐛 Известные проблемы

- Нестабильные селекторы на некоторых страницах — промпты включают несколько XPath/CSS и fallback через JS-клик.
- Если список доступных языков формируется динамически, LawyerAgent может запросить уточнение языка у пользователя.
