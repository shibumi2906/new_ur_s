# Инструкции по установке и настройке

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации

Создайте файл `.env` в корневой директории проекта:

```bash
cp env_example.txt .env
```

Отредактируйте файл `.env` и укажите ваши данные:

```env
OPENAI_API_KEY=your_openai_api_key_here
PROXY_URL=your_proxy_url_here
DEFAULT_EMAIL=your_email@example.com
DEFAULT_PASSWORD=your_password
```

### 3. Тестирование установки

```bash
python test_agent.py
```

### 4. Запуск агента

```bash
python run_agent.py
```

## 🔧 Подробная настройка

### Требования к системе

- Python 3.8+
- Chrome браузер
- Доступ к интернету
- OpenAI API ключ

### Установка Chrome WebDriver

WebDriver будет установлен автоматически через `webdriver-manager`, но убедитесь, что у вас установлен Chrome браузер.

### Настройка прокси (опционально)

Если вы используете прокси, убедитесь, что URL прокси указан в правильном формате:

```
http://username:password@proxy_host:port
```

### Настройка OpenAI API

1. Получите API ключ на [OpenAI Platform](https://platform.openai.com/api-keys)
2. Добавьте ключ в файл `.env`
3. Убедитесь, что у вас есть доступ к модели GPT-4o

## 🧪 Тестирование

### Запуск тестов

```bash
python test_agent.py
```

Тесты проверяют:
- Импорты всех модулей
- Конфигурацию
- Систему памяти

### Ручное тестирование

1. Запустите агента: `python run_agent.py`
2. Введите учетные данные
3. Наблюдайте за процессом автоматизации
4. Отвечайте на вопросы агента при необходимости

## 🐛 Устранение неполадок

### Ошибка импорта модулей

```bash
# Убедитесь, что вы находитесь в корневой директории проекта
cd /path/to/your/project
python test_agent.py
```

### Ошибка WebDriver

```bash
# Переустановите webdriver-manager
pip uninstall webdriver-manager
pip install webdriver-manager
```

### Ошибка OpenAI API

1. Проверьте правильность API ключа
2. Убедитесь, что у вас есть доступ к модели GPT-4o
3. Проверьте баланс аккаунта OpenAI

### Ошибка прокси

1. Проверьте правильность URL прокси
2. Убедитесь, что прокси работает
3. Попробуйте отключить прокси для тестирования

## 📝 Логирование

Для включения подробного логирования добавьте в начало `main.py`:

```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

## 🔒 Безопасность

- Не коммитьте файл `.env` в репозиторий
- Используйте сильные пароли
- Регулярно обновляйте API ключи
- Ограничьте доступ к файлам с учетными данными

## 📞 Поддержка

При возникновении проблем:

1. Проверьте логи ошибок
2. Убедитесь, что все зависимости установлены
3. Проверьте конфигурацию
4. Создайте Issue с описанием проблемы
